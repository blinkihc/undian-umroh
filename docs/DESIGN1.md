## Brand & Style

### Personality & Tone
The design system embodies the high civic integrity of regional governance merged with the sacred, celebratory grandeur of an Islamic pilgrimage award. It projects absolute auditability, institutional authority, and public transparency, shifting seamlessly into an elevated, celebratory aesthetic during live public stage drawings. 

Key attributes:
- **Resmi & Terpercaya (Official & Credible):** Clean, rigorous tabular structures, explicit cryptographic proofs, and uncompromising data integrity.
- **Transparan & Akuntabel (Transparent & Accountable):** Verification hashes, audit trails, and strict data masking visible upfront.
- **Megah & Khidmat (Grand & Dignified Islamic Celebration):** Deep royal indigos, noble emerald accents, and sacred gold highlights calibrated specifically for large-venue stage projection.

### Target Audience & Surfaces
1. **Administrative Workspace (Panel):** Civil servants and audit committee members handling strict participant data, validation workflows, and system locks. Prioritizes low cognitive load, information density, and fail-safe confirmation flows.
2. **Projector Screen (Layar Undian 16:9):** Public spectators, regional leaders, and legal witnesses viewing from 5–30 meters away. Built with high-contrast, bold typography and dynamic reveal choreography.
3. **Public Verification Portal (Publik):** Citizens verifying regional tax records and raffle results on mobile and desktop viewports.

### Design Movement
**Modern Civic Institutional with Sacred Grandeur:** A hybrid of crisp, utilitarian administrative UI (high-contrast neutral cards, functional monospace data streams, and clear status chips) paired with an illuminated stage presence using geometric eight-pointed Islamic star motifs, balanced elevation tiers, and gold-rimmed focal structures.

## Colors

### Hierarchy & Functional Assignment
- **Primary (`#0B4F9C` / `primary-700`):** Represents Bapenda authority. Applied to primary CTAs, active navigational strokes, critical action pathways, and active link states.
- **Deep Stage Canvas (`#062A55` / `primary-900`):** Serves as the immersive background for the 16:9 stage projector view and dark executive headers.
- **Secondary (`#1E8F3A` / `secondary-600`):** Derived from the Pemkab OKU Selatan regional crest. Applied to decorative stage ribbons, affirmative progress indicators, and celebratory accents.
- **Accent Gold (`#F5C518` / `accent-400`):** Reserved exclusively as an accent. Applied to the winner card halo, pointer chevrons, stage confetti, and verified winner honors. Must never be used for small running body text.
- **Neutral Stack:**
  - `#FFFFFF` (`neutral-0`): Primary canvas for Panel and Public portals.
  - `#F5F8FC` (`neutral-50`): Surface tier for cards, sidebar backdrops, and secondary wells.
  - `#CBD5E1` (`neutral-300`): Structural containment borders.
  - `#475569` (`neutral-600`): Subtitles, metadata, and placeholder text.
  - `#0F172A` (`neutral-900`): High-legibility body copy and dominant headlines.

### Accessibility & Contrast Principles
All text pairings under 24px must maintain minimum WCAG 2.1 AA compliance (4.5:1 ratio), with key administrative elements targeting AAA (7:1+):
- Primary button (`#FFFFFF` on `#0B4F9C`): 8.0:1 (AAA).
- Projector Stage text (`#FFFFFF` on `#062A55`): 14.3:1 (AAA).
- Accent Gold on Deep Stage (`#F5C518` on `#062A55`): 8.8:1 (AAA).
- Never signify operational status via color alone; color codes must always pair with descriptive text and distinct iconography.

## Typography

### Structural Philosophy
The typographical hierarchy balances regional administrative order with stage visibility:
- **Plus Jakarta Sans:** Drives all headers, modal titles, and prominent stage presentation labels, providing a warm, modern, and commanding Indonesian government aesthetic.
- **Inter:** Powers all administrative forms, audit records, and public informational copy. Configured with `font-variant-numeric: tabular-nums` for aligned tax figures, dates, and counts.
- **JetBrains Mono:** Dedicated exclusively to technical data requiring visual verification: SHA-256 hashes (`snapshotHash`), masked NOP sequences (`16.09.030.xxx.xxx-0003.0`), and masked NIK sequences (`1609xxxxxxxx0012`).

### Offline Font Deployment
All font assets must be locally bundled at build time using self-hosted files. External runtime font calls to public CDNs are prohibited to ensure uninterrupted operation during offline or air-gapped auditor drawings.

### Projection Legibility Rules (16:9 Display)
Text rendered on the stage projector must remain readable from the back row of an auditorium:
- Winner Name: `display-stage` (96px, 800 weight).
- Animated NOP Mask: `headline-stage-lg` (64px, 700 weight, monospace tabular numbers).
- Event Title & Category Slots: `headline-stage-md` (48px–56px).
- Absolute minimum font size for stage viewing is 28px (with the sole exception of the 64-character full SHA-256 hash at 20px, intended for photographic witness records).

## Layout & Spacing

### System Foundations
The design system employs a rigid 4px spatial base unit, scaling across a modular system (`4px`, `8px`, `12px`, `16px`, `24px`, `32px`, `48px`, `64px`, `96px`).

### Layout Engines
1. **Administrative Panel:** 12-column fluid grid system bounded by a max container width of 1280px. Standard gutters are 24px (`gutter`), with 32px outer canvas margins (`margin`). Internal form fields maintain a 16px gap (`space-md`), and structural card groupings maintain a 32px gap (`space-xl`).
2. **Stage Projector Canvas (Layar Undian):** Fixed 16:9 aspect ratio (reference resolution 1920×1080). Operates on a safe-area margin of 5% (96px horizontal, 54px vertical) to ensure zero clipping on diverse hardware projection models. Layout elements scale via `clamp()` linked to viewport height and use spatial tokens of 32px and above (`space-xl` through `space-4xl`).
3. **Public Portal:** Adapts from a single-column stacked layout on mobile (0–767px) with 16px margins to a structured two-column layout on tablet/desktop (≥768px).

### Breakpoints & Reflow
- **Mobile (0–767px):** Full-width stacked cards, tables reflow into discrete cards, touch targets maintain a minimum 44×44px hit-box.
- **Tablet (768–1279px):** Dual-region lottery summaries align side by side; administrative panel switches the fixed sidebar to a sliding drawer.
- **Desktop (≥1280px):** Optimized primary operational state for civic administration and data locks.

## Elevation & Depth

Visual hierarchy is communicated through structural tonal layers on administrative screens, transitioning to illuminated ambient depth on stage surfaces.

### Administrative Panel & Public Views
- **Base Level (Canvas):** Pure `#FFFFFF` or `#F5F8FC` surface.
- **Level 1 (Cards & Tables):** Flat white container enclosed by a 1px `neutral-300` border, grounded by an subtle ambient shadow: `0 1px 2px rgba(15, 23, 42, 0.06)`.
- **Level 2 (Popovers, Toasts, Dropdowns):** Elevated cleanly above workspace tables with `0 4px 12px rgba(15, 23, 42, 0.08)` and a crisp 1px `neutral-300` perimeter border.
- **Level 3 (Modal Confirmation Dialogs):** Centered overlay supported by a backdrop blur (`backdrop-blur-sm`) tinted with `rgba(6, 42, 85, 0.40)` to isolate high-stakes actions like locking tax records.

### Stage Projector (Layar Undian)
- **Atmospheric Depth:** Deep linear gradient originating from `primary-900` (`#062A55`) transitioning to `#0A3A73`, overlaid with an 8-pointed geometric Islamic pattern set at 6% opacity using `secondary-600`.
- **Winner Reveal Elevation:** The stage Winner Card utilizes an authoritative stage shadow: `0 16px 40px rgba(6, 42, 85, 0.50)` complemented by an illuminated celebratory outer glow: `0 0 0 4px #F5C518`.

## Shapes

The interface balances formal civic authority with modern software standards through balanced corner geometry:

- **Small (`6px` / `0.375rem`):** Applied to form text inputs, dropdown triggers, tabular action buttons, and numeric badges.
- **Medium (`10px` / `0.625rem`):** The primary radius across the system. Applied to administrative content cards, standard interactive buttons, and the dual-emblem regional logo plate.
- **Large (`16px` / `1rem`):** Reserved for high-importance surfaces, including confirmation modals, public verification containers, and the primary stage Winner Card (`kartu pemenang`).
- **Pill (`9999px`):** Applied exclusively to status indicator chips, toggle switches, and the year-clearance verification tags (`2022–2026`).

### Logo Placement Plate
The official Pemkab OKU Selatan crest and Bapenda logo must always sit side by side on a unified white backdrop plate with `10px` (`rounded-md`) rounding whenever presented over the deep blue stage background, ensuring neither emblem's intrinsic color profile is compromised.

## Components

### Buttons
- **Primary:** Minimum 44px height (56px on stage operator bar), `primary-700` fill, white text, 600 weight, 20px horizontal padding, `10px` radius. Hover: `#093F7D`. Focus: 3px outer ring in `primary-500` at 40% opacity.
- **Secondary:** White fill, 1px `neutral-300` border, `primary-700` text. Hover: `primary-100` fill.
- **Danger:** `danger-700` fill with white text. Restricted to irreversible administrative actions (e.g., Kunci Data, Tandai Gugur, Diskualifikasi). Must always trigger a confirmation modal.
- **Operator Stage Bar:** Semi-translucent white surface (90% opacity), `neutral-900` text, keyboard shortcut indicators (`H`, `Space`, `F`, `M`) rendered in micro-capsules.

### Chips & Status Badges
Status indicators use pill geometry (`9999px`) with an explicit paired Lucide outline icon and localized text label:
- **Terkunci / Diundi / Menang:** `primary-100` background, `primary-700` text.
- **Final / Dipublikasi / Terverifikasi / Lolos:** `secondary-100` background, `success-700` text.
- **Draf / Cadangan:** `neutral-50` background, `neutral-600` text.
- **Gugur / Dibatalkan:** `danger-100` background, `danger-700` text.
- **PerluKeputusan:** `warning-100` background, `warning-700` text.

### Form Inputs & Data Fields
- Standard inputs maintain 44px height, 1px `neutral-300` border, and 6px border radius.
- Always include an explicit 14px 500-weight label positioned above the field; do not rely on placeholders as labels.
- **NOP Input:** Features `inputmode="numeric"` with automated segment formatting (`16.09.xxx...`) and dynamic visual format validation displayed immediately below the field.
- **Verification Hash Display:** Monospace block (`JetBrains Mono`), `neutral-50` container, with leading and trailing character emphasis (`8 char awal... 8 char akhir`) and an integrated one-click copy button.

### Cards
- **Panel Dashboard Cards:** Flat white surface, 1px `neutral-300` border, 24px padding, `10px` border radius. Metrics display with 32px 700-weight numbers and 14px muted description labels.
- **Winner Stage Card (Kartu Pemenang):** Spans 80% canvas width on stage, pure white fill, 16px radius, gold ambient glow (`#F5C518`), and an emerald top header banner (`secondary-600`) declaring the award tier. Organizes taxpayer data strictly: Winner Name (96px) → Masked NOP (64px) → Masked NIK → Taxpayer Address → Five consecutive annual payment clearance badges (2022–2026).

### Stage Animation Modules
Presentation animations (`slot-mesin`, `roda-nama`, `kartu-berputar`, `ticker-nop`) are strictly visual representations of the underlying data. All transitions run exclusively on hardware-accelerated CSS properties (`transform`, `opacity`) capped at 60 FPS, systematically resolving to the pre-calculated RNG winner upon operator termination.
